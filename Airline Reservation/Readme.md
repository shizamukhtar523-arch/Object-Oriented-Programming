# SkyLink Airways Airline Reservation System

## Description

Console based Airline Reservation and Flight Management System developed in C++ using Object Oriented Programming concepts.

## Features

- Flight Management
- Passenger Management
- Ticket Booking
- Ticket Cancellation
- Refund Calculation
- File Handling
- Exception Handling
- Operator Overloading
- Templates
- Inheritance
- Polymorphism

## OOP Concepts Used

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Classes

- Flight (Abstract)
- DomesticFlight
- InternationalFlight
- CharterFlight
- Passenger
- EconomyPassenger
- BusinessPassenger
- FirstClassPassenger
- Ticket
- Airline

## Compilation

Compile all cpp files together.

Example:

g++ *.cpp -o AirlineSystem

Run:

AirlineSystem.exe
